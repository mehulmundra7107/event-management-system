Event Schedule

DBMS Weak Entity and Composite Key Concept

1. Weak Entity: event_schedule cannot exist without its parent event.
2. Partial Key: schedule_id is NOT unique globally. Activity 1 exists for Event 1, and Activity 1 also exists for Event 2.
3. Composite Primary Key: Uniqueness is guaranteed only by the pair (event_id, schedule_id).
4. ON DELETE CASCADE: If a parent event is deleted from the Events page, MySQL automatically deletes all its schedule activities.
